Ocean Focus is a productivity web app built around the Pomodoro Technique, wrapped in a calm, ocean-themed interface. It combines a focus timer, task manager, and progress tracker so users can plan their day, work in focused intervals, and see their progress build over time.

Built entirely with HTML, CSS, and vanilla JavaScript — no frameworks or build tools — Ocean Focus runs directly in the browser and saves all data locally, so tasks, settings, and stats persist between sessions.

Key features:

Circular Pomodoro timer with Focus, Short Break, and Long Break modes
Task list with priorities, Pomodoro estimates, and per-task comments
Distraction-free Focus Mode overlay
Daily stats: focus time, sessions completed, tasks done, and streaks
Light ("Ocean Light") and dark ("Ocean Dark") themes
Fully responsive layout for desktop and mobile
No backend or account needed — all data stays in the browser via localStorage
